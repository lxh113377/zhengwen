## 一、先诊断，再动手（避免「用调参掩盖机制缺陷」）

### 1.1 现状核验（改造前实测）

| 英伟达最新财报 | **全 0 命中** | 拒答 |

**结论：实时层实际只对「政策文件类」问题有效。** 唯一具备真关键词检索的源只有中国政府网两个文件库；

→ 于是「离线也拒答 + 实时也 0 命中 = 高拒答」。

**因此根因是「召回不足」，不是「闸门过严」。** 这一点决定了处置方向：**不放松闸门**，
而是（a）扩召回、（b）把「查到但未核实」的内容如实交出去。

## 三、分层输出（本轮核心机制）

### 3.1 设计

| 层 | 判据 | 权限 |
|---|---|---|
| **可核实依据** `strict` | 查询**原始 bigram 命中 ≥ 2**（判据**丝毫未放松**） | 可进结论、可参与拒答判定、可送模型 |
| **相关线索** `related` | 命中 ≥ 1（最多 5 条） | **仅展示**：标「未核实」、不给引用编号、**不进结论、不进模型输入** |

**🔴 关键纪律：`related` 不参与拒答判定。** 否则「有条目沾边就放行」= 把「无依据即拒答」这个核心卖点拆掉。

### 3.2 隔离桩（层 a，33 项，不联网）

关键 5 项：

| 断言 | 结果 |
|---|---|
| 只有相关线索 + 语料无依据 → **仍必须拒答** | ✅ |
| 拒答时仍透传相关线索（不隐瞒查到了什么） | ✅ |
| 相关线索 `verified=false`、`live=true` | ✅ |
| 语料有依据 + 仅线索 → 放行，且**线索不混入结论证据** | ✅ |
| 央视网跳转壳 → 还原出真实原文地址（否则「点回原文」断链） | ✅ |

### 3.3 集成对照（层 b + 层 c，8 项）

| 断言 | 实测 |
|---|---|
| 对照·应命中 → 命中 > 0 | ✅ 6 条 |
| 对照·应无命中 → 命中 == 0，且**不得被静默放行** | ✅ |
| 层 c·「英伟达最新财报」 | ✅ 可核实 **3** / 线索 2（改造前 **0**） |
| 层 c·「2026 年诺贝尔文学奖得主」 | ✅ 可核实 **6** / 线索 3（改造前 **0**） |
| 层 c·「中国新能源汽车出口数据」 | ✅ 可核实 **6** / 线索 5 |

**自检合计 41/41 通过，exit=0**（层 a 33 + 层 b 5 + 层 c 3）。

## 四、顺带修掉的两个真实缺陷

| # | 缺陷 | 根因 | 修复 |
|---|---|---|---|
| 1 | 列表页中**普通相对路径**条目被静默丢弃 | `_abs_url` 只处理 `//` 与 `/` 开头，其余原样返回 → 下游 `startswith("http")` 判假跳过 | 改为 `urljoin` 统一解析（已是绝对链接则原样返回，幂等） |
| 2 | 央视网条目大量显示「**日期未标注**」，而时效恰恰是实时核证最要紧的字段 | 日期靠「结果块邻近 800 字符内出现 YYYY-MM-DD」抽取，部分条目抽不到 | 增加 **URL 兜底**（原文地址内嵌 `/2019/04/29/` 形态）+ 统一 `normalize_date()` 归一为 `YYYY-MM-DD` |

另新增**时效不伪装**：提问含「今天 / 最新 / 近日」等时效词且命中条目均为旧闻时，结论中显式提示最新发布日
（实测「今天天气怎么样」取回央视网天气新闻，最新发布日 2026-09-14，同时存在 2019 年旧条目）。

## 五、诚实边界（不回避）

1. **边界变更留痕**：「今天天气怎么样？」
   - 改造前实测实时 0 条 / 离线 0 条 → **判为应拒答是正确的**（当日条件下为真，按 R241 保留原值）；
   - 改造后央视网检索可用，该问能取回**真实天气新闻**（含 2026-09-14 条目）→ 再要求拒答与用户
     「任何问题都实时查证权威媒体」的意图冲突。
   - **处置：变更的是用例，不是闸门。** 负样本改用与新闻语料无词面交集的查询
     （「帮我给这只猫起个名字吧」「请帮我写一段 Python 爬虫代码」），继续守住「闸门未被放宽」。
2. **边界留痕**：「红烧肉怎么做才好吃」
   - 改造前拒答；扩源后央视网**确有该主题的真实条目** → 现取回（可核实 6 / 线索 2）。
   - 这不是编造（条目真实、可点回原文），但说明本层**不区分「新闻 / 非新闻」意图**，只按词面相关性与来源权威性取回。
   - 已在《应用方案》§7.5 与《材料数字对照表》如实披露，**不写成「只答新闻类问题」**。
3. **覆盖面仍非全网**：中央媒体中仅**央视网**站内检索可用，人民网 / 新华网 / 光明网 / 百度 / 头条均不可得。
   **材料中禁止**写成「全网实时检索」「覆盖全网权威媒体」。
4. **通用检索插槽未配置**：代码就绪并支持按权威域过滤，**未配置凭据即如实标注「未启用」**。
5. **历史证据不作废但要带注**：`raw/live-20260919-031745.json`、`raw/live-20260919-031821.json`
   为**改造前**快照，其中「央视网站内检索不可用」「今天天气应拒答」等结论当时为真，
   现已被本轮结论取代 → 引用这两份时必须同时引用本文件的更正说明。
