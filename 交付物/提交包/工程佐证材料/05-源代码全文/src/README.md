# 证闻 · 源码说明

> 作品：**证闻** —— 对话式新闻智能体（求证 + 新闻，谐音「正文」）
> 赛事：2026 年 iCAN 大学生创新创业大赛 · AI 应用创新挑战赛 · 软件赛道 · 高校组
> 提交截止：2026-09-30

---

## 一句话

把新闻从「单向阅读」变成「可追问、可溯源」——**每一条结论都能点回原文**；
语料里没有依据时**明确拒答**，而不是编一段听起来对的话。

## 快速运行

### 环境要求

| 项 | 要求 |
|---|---|
| Python | **3.10+**（开发环境实测 3.12.2） |
| 第三方依赖 | **无**（纯标准库） |
| 浏览器 | 支持 WebGL 的现代浏览器（无 WebGL 时自动降级为静态版面，内容不缺失） |

### 启动

```bash
cd src
python app.py
```

打开 `http://127.0.0.1:8848/`

可选环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 监听地址；部署到公网改为 `0.0.0.0` |
| `PORT` | `8848` | 监听端口 |
| `LLM_API_KEY` | 空 | **不配置即为规则版**；配置后走在线大模型 |
| `LLM_BASE_URL` | `https://api.deepseek.com/v1` | OpenAI 兼容端点 |
| `LLM_MODEL` | `deepseek-chat` | 模型名 |
| `LLM_PROVIDER_NAME` | `DeepSeek` | 界面与材料中**如实标注**的供应商名 |

> 🔴 **密钥纪律**：本仓库**不含任何密钥**，也不提供 `.env`。密钥仅通过环境变量注入，
> 禁止写入源码、日志或交付物。

## 实时核证层（`live.py`）

**为什么需要**：只在固定语料里检索，回答不了语料之外的问题 —— 那是「假查证」。
本层在收到提问时**实时**向白名单权威源发起检索，命中的才给结论并回链原文。

**通道类型**（逐源实测结论见 `/api/live/sources`，不在此复述以免双源漂移）：

| 类型 | 说明 |
|---|---|
| 站内检索（JSON API） | 中国政府网 · 国务院文件库 / 部门文件库（真关键词检索） |
| 最新条目池 + 关键词过滤 | 人民网首页 / 新华网首页 / 央视网新闻 / 联合国新闻（中文） / WHO |
| 原文摘录 | 对命中的原文 URL 抽正文，截取含查询词的那一段（点回原文的落点） |
| 通用检索插槽（可选） | 配置 `WEB_SEARCH_API_URL` / `WEB_SEARCH_API_KEY` 后并入全网检索结果 |

**双轨合并与拒答语义**：离线语料与实时源**各查各的**，证据合并展示并分别标注来源与抓取时间；
**只有两条路都没有可核实依据时才拒答**。相关性判定一律用**查询原始 bigram**（≥2 命中），
查询变体只用于扩召回，**不放松判据**。

**降级不伪装**：单源失败只记录到逐源状态里，不影响其它源；总超时到点即用已到达结果收口；
全部源失败时标 `offline` 并在界面明示「本次未能完成联网核实」，绝不编造。

环境变量（均可选）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `LIVE` | `1` | 设为 `0` 关闭实时检索（只走离线语料） |
| `LIVE_PER_SOURCE_TIMEOUT` | `8` | 单源超时（秒） |
| `LIVE_TOTAL_BUDGET` | `13` | 整轮实时检索总预算（秒） |
| `LIVE_MAX_MERGED` | `8` | 合并后送入模型的证据上限（实时优先） |
| `WEB_SEARCH_API_URL` / `WEB_SEARCH_API_KEY` | 空 | 通用检索插槽（Tavily / 博查 / Serper 兼容） |

## 三个核心机制（对应评分判据）

| # | 机制 | 落点 | 怎么验证 |
|---|---|---|---|
| 1 | **证据约束生成** | `llm.py` SYSTEM_PROMPT 硬性规则 1—6；离线语料与实时证据都必须来自本次检索结果 | 回答里每个引用编号都能点开看到原文；实时引用额外显示来源与抓取时间 |
| 2 | **无依据即拒答** | 离线闸门（`rag.py`，阈值 0.34 + 原始词命中 ≥2）× 实时相关性闸门（`live.py`，原始 bigram ≥2）：**两条路都无依据才拒答** | 问「今天天气怎么样」→ 拒答并逐条写明「离线语料 + N 个实时源均未找到可核实依据」 |
| 3 | **降级不伪装** | `llm.py`：模型失败 → 规则版（`mode` 驱动前端徽章）；`live.py`：源失败/超时逐条列出，全部失败标 `offline` | 不配 Key 启动 → 显示「规则版」；断开网络提问 → 明示未完成联网核实 |

## 语料与许可

本项目有**两类内容**，界面与接口必须分别标注，不得混同：

1. **离线固定语料**（`src/corpus/`）：S0 自建**合成**语料（本项目原创，非真实新闻报道；人物、机构、数字均为虚构）
   + 世界银行开放数据（CC BY 4.0）。界面以 `演示数据` / `合成演示 + 公开来源` 徽章标注。
2. **实时核证证据**（`src/live.py` 提问时抓取）：来自白名单公开权威源，**逐条**携带来源、许可、
   发布时间、**抓取时间**与原文链接；界面以「实时」徽章与离线内容区分。

🔴 **引用粒度纪律（合规要点）**：实时源一律**只保留标题 / 文号 / 发文机关 / 短摘录（≤280 字）+ 原文链接**，
**不转载全文**、不缓存整篇、不做二次分发。每源条款见 `/api/live/sources`。

外部来源许可核实结果见 `交付物/提交包/语料来源台账.md`（世界银行 CC BY 4.0 已核实可商用；
维基百科 CC BY-SA 4.0 须署名 + 相同方式共享）。⚠️ 中国政府网的内容此前结论为「禁止商业性**原版原式转载**」——
本项目因此**只做短摘录 + 原文链接**，不转载全文；该项已在《实时源登记表》中逐条登记，供复核。

第三方组件：**Three.js**（MIT）、**GSAP / ScrollTrigger**（标准免费许可，含商业用途，2026-09-18 核实）。
运行时**无第三方 Python 依赖**（实时核证层同样只用标准库 `urllib` / `concurrent.futures` / `xml` / `json`）。
