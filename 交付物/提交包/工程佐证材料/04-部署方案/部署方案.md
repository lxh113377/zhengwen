# 部署方案

> 用途：佐证 29 号第 6 页官方要求「对于网页应用，**确保链接稳定可访问**」。
> 建立：2026-09-19 ｜ 状态：**三层入口已部署并实测 200**

---

## 一、设计目标与约束

| # | 约束 | 应对 |
|---|---|---|
| 1 | 评委按链接访问，**复赛为线上评选**（29 号第 5 页） | 提供**免登录只读入口**，零注册门槛 |
| 2 | 链接必须**稳定可访问** | 三层冗余：任一失效仍有兜底 |
| 3 | 演示环境不得污染数据 | 只读模式**服务端强制**，写方法一律 403 |
| 4 | 网络异常时仍要能看到东西 | 静态快照站**零外部依赖**，可离线打开 |
| 5 | 降低复现成本 | **运行时零第三方依赖**（纯 Python 标准库 + 本地化前端库） |

## 三、运行时依赖（关键：**零安装**）

| 项 | 要求 |
|---|---|
| Python | **3.10+**（开发与实测环境 Python 3.12.2 / Windows） |
| 第三方包 | **无** —— 服务端、检索、生成全用标准库 |
| 前端库 | **已本地化**至 `web/vendor/`（Three.js / GSAP / ScrollTrigger，785 KB），**不依赖 CDN** |
| Node / 构建 | **不需要** —— 原生 HTML / CSS / JS |
| 字体 | 系统字体（PingFang SC / Microsoft YaHei / SimSun 等），**无商业字体文件** |

> 为什么坚持零依赖 + 本地化 vendor：CDN 不可达是演示事故最常见来源；且评委断网环境下仍需可演示。

## 四、只读语义（服务端强制，非前端隐藏按钮）

| 请求 | 只读模式响应 |
|---|---|
| `GET /api/health` | 200，`readonly: true` |
| `POST /api/ask` | 200（仅读语料，无副作用） |
| `PUT` / `DELETE` / `PATCH` / 非 `/api/ask` 的 `POST` | **403** |
| 会话状态 | `sessions_tracked` **恒为 0** |

评委可自行复验（对任一入口执行）：

```text
GET  /api/health            → 200，readonly: true
POST /api/ask {"query":"…"} → 200
PUT  /anything              → 403
GET  /api/health            → sessions_tracked 仍为 0
```

## 五、环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 公网部署改 `0.0.0.0` |
| `PORT` | `8848` | 监听端口 |
| `READONLY` | 空 | 置 1 = 只读模式（等价 `--readonly`） |
| `LLM_API_KEY` | 空 | **不配置即为规则版**；配置后走在线大模型。**当前线上实例已注入**（2026-09-19，`adf6ce20…`）：`/api/health` → `model_available: true` / `provider: DeepSeek`；线上实测应放行 `mode=model`（**2476—3653 ms**，含网络往返），应拒答仍 `mode=rule`。注入方式：**仅经运行环境变量传递，不写入仓库任何文件**（实操：`export LLM_API_KEY=…` 后重启服务进程）；移除凭据即回到「规则版 + 原因」，**不冒充大模型生成** |

> 🔴 **密钥纪律**：密钥**仅经环境变量注入**，不写入源码、日志、本目录或任何交付物。提交包已扫描确认零密钥形态。

## 六、故障转移路径

```text
云沙箱不可达  → L3 静态快照站（离线可开，含完整问答流程与证据回链展示）
                仍不可        → L1 本地（源码包内 python app.py，零依赖）
WebGL 不可用  → 自动降级为静态叙事版面，**内容不缺失**（不依赖 canvas）
模型不可用    → 自动降级为规则版，界面与接口标注「规则版 + 原因」，不冒充大模型生成
```
