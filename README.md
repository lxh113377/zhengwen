## 三条最重要的结论（来自主报告）

1. **「省一等奖」不是官方术语** —— 官方赛程为「复赛（10 月 · 线上评选）→ 全国总决赛（11 月）」，材料须统一用「复赛一等奖」。
2. **2026 的评分措辞与 2025 不同** —— 2026 已删除「低代码/无代码平台」，改为「技术路线合理性 + AI 能力运用深度 + 系统稳定高效」，禁止套用旧表述。
3. **往届获奖作品没有公开代码** —— 实测检索结论为「不存在」（数据缺失）；可对标的是官方披露的获奖特征与官方入围名单原文，不是网络流传的"获奖源码"。
