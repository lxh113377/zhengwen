> **把新闻从「单向阅读」变成「可追问、可溯源」—— 每一条结论都能点回原文。**

## 一、它解决什么问题

新闻正在被「摘要化」，但摘要丢掉的恰恰是最重要的东西——**依据**。
大模型可以流畅地生成任何内容，却无法保证每条结论都能指回原文。

「证闻」把这件事反过来做：**先说依据，再给结论；没有依据，就不回答。**

| 能力 | 行为 |
|---|---|
| **证据回链** | 每条结论都能点回原文出处，附带来源、许可与抓取时间 |
| **无依据即拒答** | 检索不到可核实依据时**明确拒答**，不拿模型生成内容兜底 |
| **分歧显式** | 多来源结论冲突时**并列展示**，不替用户裁决 |
| **降级不伪装** | 在线模型不可用时降级为规则版，界面标注「规则版 + 原因」，**不显示「AI 生成」徽章** |
| **决策轨迹** | 展示「这个答案是怎么来的」，全过程可复核 |

## 三、本地运行（零安装）

要求：**Python 3.10+**。服务端、检索、生成全部使用 Python 标准库，**无需安装任何第三方包**；前端库已本地化，**不依赖 CDN**。

```bash
cd src
python app.py                # 完整演示   → http://127.0.0.1:8848/
python app.py --readonly     # 只读演示   → http://127.0.0.1:8848/demo
```

Windows 亦可直接双击 `src/run.cmd`（完整）或 `src/run-readonly.cmd`（只读）。

**只读语义由服务端强制**（非前端隐藏按钮）：`PUT` / `DELETE` / `PATCH` 与非 `/api/ask` 的 `POST` 一律返回 **403**；只读模式下会话状态计数恒为 0。

### 自检命令

```bash
python rag.py                          # 离线检索与拒答判据    期望 23/23
python live.py --selftest              # 实时核证分层判据      期望 41/41
python tools/verify_layered_output.py  # 分层输出端到端        期望 19/19（需先启动 app.py）
```

## 四、仓库结构

```text
zhengwen/
├── src/                     # 主程序（Python 标准库，运行时零第三方依赖）
│   ├── app.py               # HTTP 服务与路由（含只读模式强制）
│   ├── rag.py               # 离线检索与拒答判据
│   ├── live.py              # 实时核证层（多权威源 + 分层输出）
│   ├── llm.py               # 在线模型接入（无凭据自动降级为规则版）
│   ├── corpus/              # 语料：自建合成（原创）+ 世界银行开放数据（CC BY 4.0）
│   └── web/                 # 前端：原生 HTML/CSS/JS + 本地化 vendor（Three.js / GSAP）
├── docs/                    # GitHub Pages 站点（由 src/web 与静态快照站导出）
├── 交付物/提交包/            # 参赛交付材料（应用方案 PDF、佐证材料、台账等）
└── .gitignore
```

> `docs/` 是 Pages 的部署产物：`docs/index.html` = 静态快照站，`docs/demo/` + `docs/web/` = 前端展示副本。
> 权威源始终是 `src/web/`，`docs/` 由它同步导出。

## 六、免责与边界声明

- 演示环境使用**合成演示数据**（界面徽章标注「合成演示」）与**真实开放数据**（世界银行，CC BY 4.0，逐条标注许可与原文入口）。
- AI 输出为**参考信息**，不替代用户判断；系统在无依据时**明确拒答**，模型不可用时自动降级为规则版并如实标注来源与原因。
- 实时核证采用**两层输出**：**可核实依据**（原始词命中 ≥2）才进结论并参与拒答判定；**相关线索**（命中 ≥1）仅展示并标注「未核实」，不进结论、不进模型输入。
- 实时源覆盖**有限且已如实披露**（12 个可用源 / 19 项实测不可用，逐条留痕），**不得理解为「覆盖全网」**。
- 引用的公开资料见《应用方案》附录来源台账（含 URL 与访问日期），外源一律短摘录并附原文链接。
